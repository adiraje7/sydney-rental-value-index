#  Sydney Rental Value Index (SRVI)

> A professional end-to-end data analytics case study investigating which Sydney suburbs provide the best rental value by combining housing prices, demographics, transport accessibility, public infrastructure and socioeconomic indicators.

---

# Business Problem

Sydney is one of the world's most expensive rental markets.

While rental platforms allow users to compare prices, they don't answer a much more important question:

> **Which suburb actually provides the best value for money?**

This project develops a Rental Value Index (SRVI) to identify suburbs that provide the strongest balance between affordability, accessibility and liveability.

---

# Objectives

- Build an end-to-end analytics pipeline
- Integrate multiple Australian datasets
- Perform SQL and Python analysis
- Develop a Rental Value Index
- Build an executive Tableau dashboard
- Produce a professional research report
